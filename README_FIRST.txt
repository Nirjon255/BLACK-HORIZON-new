BLACK HORIZON - FRESH GODOT 4 PROJECT
=====================================

This is a clean, expandable Godot 4 starter project for an original tactical
military first-person/third-person action game.

IMPORTANT SCOPE NOTE
--------------------
This is a playable foundation/prototype, not a finished commercial game.
It includes:
- Main menu and mission selection for an eight-mission campaign outline
- One playable training/operation environment
- First-person / third-person camera toggle (V)
- WASD movement, mouse look, sprint, jump
- Rifle hitscan firing, ammo and reload
- Basic hostile target dummies with health
- Intel pickup and extraction objective flow
- On-screen HUD and mission status
- Low-cost procedural environment geometry
- Godot 4 Compatibility renderer

The eight campaign missions are outlined in data. Only Mission 1 has a playable
prototype environment in this initial foundation. Each later mission needs its
own designed level, encounters, objectives, art and testing.

HOW TO OPEN
-----------
1. Extract the ZIP to a normal folder, e.g. Documents/BLACK_HORIZON_Fresh_Start.
2. Open Godot 4.
3. In Project Manager choose Import.
4. Browse to the extracted folder and select project.godot.
5. Import, then press F6 only if you want to run the current scene; normally
   press F5 to run the project.
6. If Godot asks to create/import assets, allow it to finish.

CONTROLS
--------
W A S D       Move
Mouse         Look
Shift         Sprint
Space         Jump
V             Toggle first-person / third-person
Left Mouse    Fire
R             Reload
Esc           Release mouse / pause menu

PERFORMANCE
-----------
The project uses the Compatibility renderer and simple geometry to reduce
GPU load. Start at 1280x720. Lower the window size if performance is poor.
The laptop's actual FPS will depend on drivers, thermals and GPU selection.
